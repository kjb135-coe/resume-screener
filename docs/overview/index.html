The headline is a range, and that is the point

Run the identical configuration four times, changing nothing. Macro-F1 lands somewhere different each time:

run 10.788
run 20.833
run 30.838
run 40.837
Axis starts at 0.75, not 0, so the spread is visible. The bars are not proportional to zero.

The noise band is 0.051. That is the width of the ruler. Any difference smaller than it has not been measured — it has been observed once. Establishing this retroactively invalidated several earlier conclusions in this project, including one whole experiment whose entire range was 0.018.

The finding that changed the design

Every model was being judged against score cutoffs fitted to one model. Models grade on different scales, so that measures calibration, not judgment.

The same model went from worst to best without a single change to the model, the prompt, or the evidence. A fixed score threshold is part of the harness, not the model.

The tie-breaker moves a score by 0.33 on average, so if the score sits far from a decision boundary it cannot change the verdict — 92% of those calls changed nothing. And panel disagreement turned out to be a poor predictor of a wrong answer; distance to a boundary is a much better one.

What this does not prove

The corpus is synthetic. All 60 resumes were generated and their labels come from the archetype each was generated from. Every number here is agreement with an intended verdict, not with a hiring manager.

The cutoffs were fitted on the same corpus they are scored against. Cross-validation makes them honest — cutoffs are chosen on 4/5 of the data and tested on the fifth — but no held-out corpus exists.

About half the errors ship unreviewed. The system is wrong on ~13% of candidates and a human sees 15%. Reviewing a sixth of a stack cannot catch most of the mistakes in it. That is arithmetic, not a tuning failure.

There is no bias audit. The corpus has no demographic variation, so nothing here says whether scores move when a name changes. This is the most important open gap.

How it works

1. An agent reads your job posting and writes three scoring dimensions from it. 2. A cheap agent pulls verbatim quotes out of each resume. 3. Three agents score in parallel, one dimension each, never seeing each other. 4. A tie-breaker runs only when the panel straddles a boundary and sits close enough to it to be moved. 5. A human is asked only for genuinely borderline calls.
